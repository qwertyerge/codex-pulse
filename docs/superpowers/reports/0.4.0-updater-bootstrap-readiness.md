## Two-Stage Bootstrap Boundary

`0.4.0` is the manually installed updater bootstrap. Its production endpoint
uses GitHub's `releases/latest` path. GitHub's
[latest-release contract](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)
excludes Drafts and prereleases, so the exact production `0.4.0` binary cannot
discover a `0.4.1` Draft.

The first honest production automatic-update acceptance therefore occurs only
after `0.4.1` is published. Installed `0.4.0` binaries must then prove the real
`0.4.0` to `0.4.1` path on macOS ARM64 and Windows 11 x64.
