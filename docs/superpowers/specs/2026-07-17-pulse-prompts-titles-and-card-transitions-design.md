# Codex Pulse：用户消息、标题与任务卡动画设计

## 目标

让 Pulse 的标题与 Codex 侧边栏一致；在最近事件前展示最近一次用户消息；启动时以既有最大尺寸最大化窗口；让任务卡进入与退出列表时有轻量 slide 动画。

## 数据源与优先级

- 标题优先来自 `~/.codex/session_index.jsonl` 的 `thread_name`，这是 Codex 侧边栏的实际短标题。
- 当索引不存在、记录缺失或标题为空时，回退 `state_5.sqlite.threads.title`；最后回退现有未命名标题。
- JSONL 会话扫描提取最后一条 `user_message`，根会话聚合自身与子会话的最新记录。

## 交互

- 卡片在 Recent 区域依次显示 `Last prompt` 与 `Recent`；没有最近用户消息时隐藏前者。
- 两行各自可展开。展开后固定该行的文本和相对时间；收起时立即恢复当前最新的 5 秒节流数据。展开不停止后端采集，也不影响另一行。
- 标题单行省略，标题元素附带完整原文 tooltip；路径 tooltip 保持现有行为。

## 窗口尺寸

窗口创建后先按当前显示器工作区设置最大尺寸（480 宽、工作区高度减安全边距），再最大化。系统最大化必须服从该最大尺寸，不进入全屏模式。

## 任务卡动画

- 仅活跃任务卡加入或从列表移除时，整张卡使用 180ms slide + fade 动画。
- 计时器、标题、Recent、Last prompt 的更新不触发进出场动画。
- 使用稳定的 `threadId` 作为 TransitionGroup key；减少动态效果模式下禁用动画。

## 验收

- 当前会话标题可显示 `session_index.jsonl` 的 `thread_name`，而不是 SQLite 的长首条提示。
- 每卡可显示最近用户消息和最近事件，二者独立展开冻结。
- 启动窗口处于最大化状态但不超出既有 480 宽与屏幕高度上限。
- 任务卡插入/移除有平滑动画，常规刷新无闪动。
