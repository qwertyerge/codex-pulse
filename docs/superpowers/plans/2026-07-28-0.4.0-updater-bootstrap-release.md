# Codex Pulse 0.4.0 Updater Bootstrap Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare version `0.4.0` as the first updater-capable Codex Pulse bootstrap through a separate, green, open pull request without creating a tag, Draft Release, publication, or installed-app replacement.

**Architecture:** Branch `codex/release-0.4.0` is pinned to the exact green squash merge of updater PR #17. One ownership-aware Vitest contract locks the four release-version sources, while a durable readiness report keeps automated, signing-recovery, Draft, manual-install, publication, and later `0.4.0` to `0.4.1` evidence as separate gates.

**Tech Stack:** Vue 3, TypeScript 5.9, Vitest 4, pnpm 10.33.0, Rust 2021, Cargo 1.82+, Tauri 2.11, GitHub Actions, GitHub CLI.

## Global Constraints

- Work only on branch `codex/release-0.4.0` based on exact green main commit `1aaaaaedb50f3d5b8ec77abab28704d8c9e1a4cc`.
- If fresh `origin/main` differs from that approved base before version changes begin, stop and ask through AskHuman; do not silently rebase or merge.
- Change the release version from `0.3.2` to `0.4.0` only in `package.json`, root `[package].version` in `src-tauri/Cargo.toml`, the `codex-pulse` package entry in `src-tauri/Cargo.lock`, and root `version` in `src-tauri/tauri.conf.json`.
- Do not globally replace `0.3.2`; unrelated Cargo dependencies, fixtures, historical plans, reports, and current-release README statements legitimately retain it.
- Do not change the updater endpoint, updater public key, signing configuration, GitHub Secrets, Windows install mode, release workflow, UI, schedule, privacy behavior, or updater lifecycle.
- Never print or commit the updater private key, its passphrase, Keychain contents, backup path, or sensitive storage identifiers.
- Treat the maintainer's offline-backup statement as `pending-user-evidence` until a restored key signs a benign fixture and the committed public key verifies it.
- Keep the `0.4.0` version PR Ready and open after all checks pass; do not merge it.
- Do not create or push a tag, trigger or publish a Draft Release, replace an installed app, or claim a real old-to-new automatic update.
- Preserve the two-stage rollout boundary: `0.4.0` is a manually installed bootstrap; the first production automatic-update acceptance is published `0.4.0` to published `0.4.1`.
- Use normal fast-forward pushes only; never force-push.

```ts
function packageVersionFromCargoToml(contents: string) {
  const packageStart = contents.indexOf("[package]");
  expect(packageStart, "Cargo.toml should contain [package]").toBeGreaterThanOrEqual(0);
  const nextSection = contents.indexOf("\n[", packageStart + "[package]".length);
  const packageSection = contents.slice(
    packageStart,
    nextSection === -1 ? contents.length : nextSection
  );
  const version = packageSection.match(/^version = "([^"]+)"$/m);
  expect(version, "Cargo.toml [package] should declare version").not.toBeNull();
  return version![1];
}

function codexPulseVersionFromCargoLock(contents: string) {
  const packageBlock = contents
    .split("[[package]]")
    .find((candidate) => /^name = "codex-pulse"$/m.test(candidate));
  expect(packageBlock, "Cargo.lock should contain codex-pulse").toBeDefined();
  const version = packageBlock!.match(/^version = "([^"]+)"$/m);
  expect(version, "Cargo.lock codex-pulse should declare version").not.toBeNull();
  return version![1];
}
```

Keep the existing updater endpoint/configuration assertions, but remove its
single `expect(config.version).toBe("0.3.2")` assertion so release version
ownership belongs to one test. Add this new test before the capability test:

```ts
it("keeps the bootstrap release version aligned", () => {
  const packageJson = JSON.parse(read("package.json")) as { version: string };
  const tauri = JSON.parse(read("src-tauri/tauri.conf.json")) as {
    version: string;
  };

  expect({
    packageJson: packageJson.version,
    cargoToml: packageVersionFromCargoToml(read("src-tauri/Cargo.toml")),
    cargoLock: codexPulseVersionFromCargoLock(
      read("src-tauri/Cargo.lock")
    ),
    tauri: tauri.version
  }).toEqual({
    packageJson: "0.4.0",
    cargoToml: "0.4.0",
    cargoLock: "0.4.0",
    tauri: "0.4.0"
  });
});
```
